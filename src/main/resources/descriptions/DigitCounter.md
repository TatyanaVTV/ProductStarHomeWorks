# Структура программы

Программа состоит из двух классов, обеспечивающих генерацию целочисленных данных и подсчёт чисел по категориям длины.

## Класс `IntGenerator`

**Назначение:** генерация целочисленных данных — отдельных чисел или списков чисел в заданном диапазоне с валидацией входных параметров.

**Поля:**
* `private static final Random RND` — экземпляр генератора случайных чисел, используемый для всех операций генерации.

**Методы:**
* `public static List<Integer> generateListOfNumbers(int count, int min, int max)` — создаёт список из `count` случайных чисел в диапазоне `[min, max]` (включительно). Использует поток `Random.ints()` для эффективной генерации.
* `public static int generateNumber(int min, int max)` — возвращает одно случайное число в диапазоне `[min, max]` (включительно), используя `Random.nextInt()`.
* `private void checkCount(int count)` — проверяет, что параметр `count` неотрицательный; выбрасывает `IllegalArgumentException`, если условие не выполнено.
* `private void checkMinMax(int min, int max)` — проверяет, что `min ≤ max`; выбрасывает `IllegalArgumentException` в противном случае.

**Особенности:**
* Все методы — статические, класс не требует создания экземпляров.
* В методах генерации выполняется предварительная валидация параметров через приватные методы проверки.
* Потокобезопасность: `Random` не является потокобезопасным, но в рамках текущего использования (статическое поле) риски минимальны при условии, что нет требований к строгой детерминированности результатов в многопоточности.

## Класс `DigitCounter`

**Назначение:** подсчёт количества чисел разной разрядности (двузначных, трёхзначных, четырёхзначных) в списке с использованием многопоточности для повышения производительности.

**Поля:**
* `private final AtomicInteger twoDigitCount` — счётчик двузначных чисел (10–99).
* `private final AtomicInteger threeDigitCount` — счётчик трёхзначных чисел (100–999).
* `private final AtomicInteger fourDigitCount` — счётчик четырёхзначных чисел (1000–9999).

**Методы:**
* `public void processNumbers(List<Integer> numbers)` — обрабатывает входной список чисел: запускает три параллельных потока, каждый из которых фильтрует числа по своей категории разрядности и увеличивает соответствующий счётчик. Дожидается завершения всех потоков.
* `public int getTwoDigitCount()` — возвращает текущее значение счётчика двузначных чисел.
* `public int getThreeDigitCount()` — возвращает текущее значение счётчика трёхзначных чисел.
* `public int getFourDigitCount()` — возвращает текущее значение счётчика четырёхзначных чисел.

**Особенности:**
* Использование `AtomicInteger` гарантирует потокобезопасность при одновременном обновлении счётчиков из разных потоков.
* Каждый поток обрабатывает весь список, проверяя принадлежность каждого числа к своей категории, — это упрощает логику, но предполагает, что список не слишком велик.
* Изоляция данных: каждый экземпляр `DigitCounter` имеет собственные счётчики, что позволяет запускать независимые подсчёты параллельно.

---

## Взаимодействие классов

Классы могут использоваться совместно для сквозного сценария:
1. `IntGenerator` генерирует тестовый набор чисел (например, 1000 случайных чисел от 1 до 10000).
2. `DigitCounter` принимает этот список и параллельно подсчитывает, сколько среди них двузначных, трёхзначных и четырёхзначных чисел.
